# Code of conduct

headgate follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussion about the work. Harassment,
personal attacks and discriminatory language are not acceptable in issues, pull requests, discussions or any other
project space.

Report unacceptable behaviour privately to the maintainer through
[GitHub's private vulnerability reporting](https://github.com/kelsayed17/headgate/security/advisories/new) (it reaches
the maintainer only) or by email to the address on the maintainer's GitHub profile. Reports are handled confidentially,
and the Covenant's enforcement guidelines apply.
